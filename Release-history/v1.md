# Release history — DataExport

## Introduction
This page lists the versions of the Data Export plugin and the notable changes of each, so a site owner knows which version they run and what an update brings.
See the [README](../readme.md) for how to use it.

## Version 1.0.0 — first release
Released: 2026-11-17. Free plugin.

### What it exports
- **Six kinds of data as CSV files**: categories, brands, suppliers, products (single products), customers, orders.
- **Texts in every active language**: name, keywords, description and content get one column per language (`name:en`, `name:vi`, `name:ja`…).
- **Orders as one row per product line**, the order details on the first row of the order; order, payment and shipping statuses by name.
- **Filters per kind**: creation dates, status, payment status, category, store (multi-store sites); **Count rows** tells how many rows the file will have before it is made.

### Opens in Excel, imports again
- **UTF-8 with BOM** (default): Excel opens it directly with Vietnamese, Japanese and every other language intact.
- **Shift_JIS** for Japanese accounting software: characters Shift_JIS cannot hold show as `?`, and the screen tells how many cells changed and the first line.
- **Formula-safe cells**: a text cell starting with `=`, `+`, `-` or `@` gets a leading `'`; numbers such as `-5` stay as they are.
- **The import format of the Data Import plugin**: move the catalog, customers and order history to another GP247 site without mapping a column.
  Categories, brands and suppliers are referenced by alias; product images are full URLs that the new site downloads.
  Use with Data Import **1.0.2 or newer** (it removes the formula-guard `'` on import).

### Runs on low-cost hosting
- Files are **built in parts while the page stays open**, with the rows written so far; close the page and it continues when you open it again. No cron, queue or command line needed.
- On a server with a command line (VPS), `php artisan data-export:run <run id>` builds a run in one go.

### Safe with customer data
- **Permissions per group**: export catalog, export customers, export orders; administrators only by default. An accountant can export orders without the customer list.
- On a multi-store site only admins at the **root store** use this screen.
- **Only the admin who made a file can download it**, through a link valid for 5 minutes; **the file is deleted after 24 hours**, or at once with **Delete file**.
- **Never exported**: passwords (hashed or not), tokens, two-factor codes, secret settings.
- Every file created and downloaded is written to the **operation log** (who, data, filters, rows — never the content of the file).

### Requirements
- GP247 Core 3.12 or newer (`requireCore` 3.12), gp247/shop installed.
- Shift_JIS needs PHP `mbstring` (available on most hosts).
